# MedHorizon v0.3.14 — 2026-07-31

Release branch: `release/v0.3.14` · Tag: `v0.3.14`

## Added

- **Research Graph sidebar in MedHorizon:** RightPane tab embeds the bound session
  graph at `/embed/graph/:id` (canvas-only). Resolve order: session bind →
  stages/by-session → title match → latest populated graph (skip empty stub);
  auto pinBind on resolve.
- **ViewportSync for embed iframe:** refit React Flow when the host size settles
  or graph content changes.

## Fixed

- UTF-8 BOM on Windows `openscience.json` no longer breaks Research Graph OpenAI
  / `/health` resolution.
- Local OpenAI-compatible gateway models default to 256k context (upgrade legacy
  32k placeholders) so compaction is less aggressive.

## Changed

- Plan 14 (orchestrator + narrow subagents) drafted under `docs/plans/`.

## Upgrade notes

- Sidebar needs Research Graph API (`:8000`) and SPA UI (`:5173` in dev, or
  sidecar-bundled UI). Optional: `VITE_RESEARCH_GRAPH_UI` / `VITE_RESEARCH_GRAPH_API`.
- Existing sessions without a bind still resolve via stages or title match when
  possible.
