# MedHorizon v0.3.12 — 2026-07-31

Release branch: `release/v0.3.12` · Tag: `v0.3.12`

## Added

- **MCP manifest cache (plan 13 task 4):** TTL + last-good manifest cache for MCP
  `listTools()` with single-flight refresh, lifecycle invalidation, and cache metrics.
  Enable with `experimental.mcp_manifest_cache: true` (default off). Optional
  `experimental.mcp_manifest_cache_ttl_ms` (default 300000).
- **Bounded tool results (plan 13 task 6):** deterministic truncation with log severity
  retention, search hit index preservation, Research Graph keep-lists, and artifact spill.
  Enable with `experimental.tool_result_bound: true` (default off).

## Upgrade notes

- Both features are **experimental and default off**. Enable one at a time during soak.
- Existing `experimental.tool_profiles` behavior is unchanged.
- MCP servers still connect the same way; caching only affects repeat `listTools()` when
  the flag is enabled.
