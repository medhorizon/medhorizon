# MedHorizon v0.3.11 — 2026-07-31

Release branch: `release/v0.3.11` · Tag: `v0.3.11`

## Added

- **Agent tool context optimization (plan 13, tasks 1/2/3/5):** context composition telemetry (system/tool/message breakdown, no secrets in logs); `agent.toolset` availability profiles separate from permissions; filter tools **before** `init()` and JSON Schema conversion; deterministic shipped profiles (`research` includes local Research Graph `atlas_*` + `stage`). Rollback: set `experimental.tool_profiles: false` to restore all-tools behavior. Tasks 4 (MCP cache) and 6 (tool-result bounding) deferred.

## Fixed

- Per-message tool allowlist: `tools["*"]: false` now keeps explicitly `true` tools instead of removing everything.
- File path traversal hardening in CLI file utilities.
- Workspace session UI relative path normalization (`relpath` helper).

## Changed

- Documented bugfix RCA index in `docs/bugfix.md` and `docs/README.md`.

## Upgrade notes

- Default agent profiles are narrower when `experimental.tool_profiles` is enabled (default). If a workflow needs a tool outside its profile, set `experimental.tool_profiles: false` in config or expand `agent.<name>.toolset`.
- MCP tools are still listed every turn (Task 4 cache not in this release).

See also [CHANGELOG.md](../../CHANGELOG.md) and [plan 13 progress](../plans/13-agent-tool-context-optimization.md).
