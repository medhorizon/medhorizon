# MedHorizon v0.3.15 — 2026-08-01

Release branch: `release/v0.3.15` · Tag: `v0.3.15`

## Added

- **TaskResult contract (plan 01):** Zod-backed TaskTool child outcome envelope
  (`success` / `partial` / `failure` / `cancelled` / `timeout`). Strict-success —
  only a fully schema-valid envelope may become `success`.
- **CI coverage report:** Test job uses `bun run test:coverage`; root installs use
  `--frozen-lockfile`.

## Changed

- **Atlas surface retirement (plan 15):** Stage + Research Graph only in the UI.
  Atlas Canvas / artifacts / account / wallet / managed billing are unreachable.
  Default right pane: Research Graph.
- **`OPENSCIENCE_ENABLE_ATLAS` default-off:** backend/CLI Atlas cloud bridge and
  auto lifecycle stay off unless set. Does not restore product UI.
- Active execution plans under `tasks/plans/`; Atlas-specific `docs/plans/` items
  superseded.

## Fixed

- Task/RLM result paths no longer promote empty or unknown status to success.

## Upgrade notes

- No action required for Stage / Research Graph users.
- If you still need Atlas cloud compatibility (non-UI), set
  `OPENSCIENCE_ENABLE_ATLAS=1`. Full UI rollback requires reverting the retirement
  commits, not only the env flag.
- Optional: `RESEARCH_GRAPH_DISABLE=1` still skips the Research Graph sidecar + plugin.

See also [CHANGELOG.md](../../CHANGELOG.md).
