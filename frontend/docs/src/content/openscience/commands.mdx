The MedHorizon command surface. For live help, run `medhorizon --help` and `medhorizon <command> --help`.

The bare `medhorizon` (no arguments) starts the local server and opens the **browser workspace** in your working directory. Everything else is grouped below.

## Global flags

| Flag | Use |
| --- | --- |
| `-v, --version` | Print the installed version. |
| `-h, --help` | Print help for a command. |
| `--print-logs` | Stream agent diagnostics to stderr. |
| `--log-level <DEBUG\|INFO\|WARN\|ERROR>` | Override the log threshold. |

## Workspace and runs

| Command | Use |
| --- | --- |
| `medhorizon` | Start the server and open the browser workspace. |
| `medhorizon run [message..]` | One-shot prompt in the terminal; streams, then exits. |
| `medhorizon session list` | List recent sessions (`-n`, `--format`). |

`run` flags: `-c/--continue`, `-s/--session <id>`, `-m/--model <provider/model>`, `--variant <high|max|minimal>` (provider-specific reasoning effort), `--agent <name>`, `--format <default|json>`, `-f/--file <path>`, `--attach <url>` (attach to a running server, e.g. `http://localhost:4096`), `--port`, `--title <text>`.

```bash
medhorizon run "Plot the attention entropy across layers for this checkpoint"
medhorizon run -c "Now sweep the temperature and re-plot"
medhorizon run --format json "Summarize the experiment in results/" > summary.json
```

## Account

Connecting an Atlas account is optional — see [Atlas](/openscience/atlas). MedHorizon runs fully standalone with your own provider keys.

| Command | Use |
| --- | --- |
| `medhorizon init` | First-run setup wizard — choose managed models, your own keys, or skip. Rerun anytime (alias `onboard`). |
| `medhorizon login` | Connect your Atlas account (browser flow, or `--key thk_…`). |
| `medhorizon status` | One view of your Atlas state — account, synced services, subscription, wallet balance + lifetime spend, recent usage, managed-compute availability, and the bundled `atlas` companion version (alias `whoami`). |
| `medhorizon sync` | Re-pull synced credentials. |
| `medhorizon devices` | List authorized devices. |
| `medhorizon logout` | Disconnect this device from Atlas. |
| `medhorizon doctor` | Report what's configured: account, provider keys, wallet, default model. |

`medhorizon connect …` still works as an alias for `login` / `logout` / `status` / `sync` / `devices`.

## Providers and routing

| Command | Use |
| --- | --- |
| `medhorizon keys add` | Add a provider API key (BYOK; OAuth sign-in where supported). Alias: `auth`. |
| `medhorizon keys signin` | Sign in with ChatGPT / Codex (subscription). |
| `medhorizon keys list` | List saved provider keys and active env vars. |
| `medhorizon keys rm` | Remove a saved provider key. |
| `medhorizon models` | List configured providers and their models. |
| `medhorizon wallet` | Wallet balance and key routing (alias `billing`). |
| `medhorizon wallet topup` | Open the app to add credit. |

## Sandbox

| Command | Use |
| --- | --- |
| `medhorizon sandbox` | Show sandbox status: OS backend + current policy. |
| `medhorizon sandbox enable` | Confine the agent's shell + notebook execution to the workspace (`--network deny`, `--allow <path>`, `--on-unavailable <warn\|error\|allow>`). |
| `medhorizon sandbox disable` | Turn the sandbox off. |
| `medhorizon sandbox test` | Prove containment on this machine (writes inside/outside the workspace, network egress). |

Off by default. See [Execution sandbox](/openscience/sandbox).

## Agent profiles

| Command | Use |
| --- | --- |
| `medhorizon agent list` | Print the agent roster on this install. |
| `medhorizon agent create` | Scaffold a custom agent (system prompt + tool set + routing policy). |

Flags: `--path`, `--description`, `--mode <all\|primary\|subagent>`, `--tools`, `--model`. See [Agents](/openscience/agents).

## Skills

| Command | Use |
| --- | --- |
| `medhorizon skill list` | Show installed skills (`--all` for the bundled set). |
| `medhorizon skill show <name>` | Print a skill's metadata and entrypoints. |
| `medhorizon skill add <url-or-name>` | Install a skill (URL or `gh:owner/repo`). |
| `medhorizon skill new` / `edit` / `validate` | Author, edit, and check user skills. |
| `medhorizon skill remove <name>` | Uninstall a skill. |
| `medhorizon skill set-entries <name>` | Update which skills surface in the `/` picker. |

## Local server and protocols

| Command | Use |
| --- | --- |
| `medhorizon web` | Start the server and open the browser workspace (prints the URL, e.g. `http://localhost:4096`). |
| `medhorizon serve` | Headless local server — loopback-only (`127.0.0.1`), no browser. |
| `medhorizon acp` | Start an Agent Client Protocol server for editors like Zed. |
| `medhorizon mcp` | Manage MCP servers (`list`, `add`, `remove`, `auth`). |

`web` and `serve` take `--port` and `--cors`. See [Workspace](/openscience/workspace).

## GitHub and PRs

| Command | Use |
| --- | --- |
| `medhorizon github` | GitHub agent for CI/Actions (`install`, `run`). |
| `medhorizon pr <number>` | Check out a PR branch, then launch the agent on it. |

## Project and lifecycle

| Command | Use |
| --- | --- |
| `medhorizon project` | Pin the Atlas project root for this folder (`merge`). |
| `medhorizon export` / `medhorizon import` | Export or import a session as JSON. |
| `medhorizon generate` | Emit the OpenAPI spec for the local server to stdout. |
| `medhorizon stats` | Local token-usage and cost stats. |
| `medhorizon debug` | Structured diagnostics for support (`debug paths` shows data/config dirs). |
| `medhorizon upgrade` | Update to the latest version. |
| `medhorizon uninstall` | Remove the binary and local config. |
| `medhorizon completion` | Shell completion for bash, zsh, or fish. |

```bash
medhorizon upgrade
medhorizon completion zsh > ~/.zsh/completions/_medhorizon
```
